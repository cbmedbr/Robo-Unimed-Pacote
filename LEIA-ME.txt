=============================================
  ROBO UNIMED - AUTORIZACAO + EXECUCAO
  Clinica Luciano Noceti
=============================================

CONTEUDO:
  servidor-local/     - Servidor HTTP que recebe comandos do CRM
  unimed-mvp-final/   - Robo Playwright (Chrome automatizado)
  instalar.bat        - Script de instalacao (rodar 1x no PC novo)
  iniciar.bat         - Script para iniciar o servidor (rodar todo dia)
  trocar-senha.bat    - Troca a senha do portal Unimed neste PC
  SENHA_VERSAO.txt    - Controle de qual senha esta valendo (nao editar)

REQUISITOS DO PC:
  - Node.js v18+ instalado (https://nodejs.org)
  - Google Chrome instalado
  - Webcam funcionando (para QR Code)
  - Acesso a internet

INSTALACAO (1x):
  1. Copie esta pasta inteira para C:\Robo-Unimed\ no PC destino
     (ou: git clone https://github.com/cbmedbr/Robo-Unimed-Pacote)
  2. Execute instalar.bat como administrador
  3. O instalador vai pedir a senha do portal Unimed e a service role key
     do Supabase, e montar o servidor-local\.env sozinho.

CREDENCIAIS:
  As senhas NAO ficam no GitHub — o repositorio e publico. Cada PC tem o
  seu proprio .env, que o .gitignore mantem fora do controle de versao.

  Para receber as credenciais, peca ao responsavel pelo robo. Use um
  gerenciador de senhas — nao mande por e-mail, WhatsApp ou dentro de
  documentos de procedimento.

QUANDO A SENHA DA UNIMED MUDA:
  Voce nao precisa avisar ninguem nem passar em cada PC. Na proxima vez
  que o funcionario abrir o iniciar.bat, o proprio robo vai parar e pedir
  a senha nova antes de iniciar. Ele pede uma unica vez por PC.

  Se o funcionario nao tiver a senha na hora, e so fechar a janela e
  abrir de novo depois - o robo nao inicia com a senha velha, pra nao
  falhar no meio de um atendimento.

  PARA O RESPONSAVEL, ao trocar a senha:
    1. Trocar a senha no portal da Unimed
    2. Editar SENHA_VERSAO.txt com a data de hoje (ex: 2026-09-01)
    3. Commitar e dar push
    4. Passar a senha nova para a equipe por gerenciador de senhas

  E o passo 2 que dispara o pedido nos PCs. Sem ele, ninguem e avisado.

  Para trocar a senha em um PC sem esperar: rodar trocar-senha.bat.

USO DIARIO:
  1. Execute iniciar.bat (ou: cd servidor-local && npm run dev)
  2. Deixe a janela do terminal aberta (pode minimizar)
  3. Use o CRM normalmente — os botoes "Executar" e "Disparar"
     chamam o robo automaticamente

DOIS ROBOS:
  - AUTORIZACAO: cria guias novas no portal Unimed
    Endpoint: POST /executar
    Acionado pela aba "Renovacao" no CRM

  - EXECUCAO: marca sessoes como realizadas no portal Unimed
    Endpoint: POST /executar-sessao
    Acionado pela aba "Aguardando Execucao" no CRM
    Requer QR Code do paciente (webcam)

PROBLEMAS COMUNS:
  - A janela do iniciar.bat abre e fecha na hora
      1. Abra de novo. Se o robo tinha acabado de se atualizar, a primeira
         tentativa falha sozinha (o git pull reescreve o iniciar.bat no meio
         da execucao) e a segunda funciona.
      2. Se continuar fechando, o iniciar.bat agora mostra o motivo e espera
         voce apertar uma tecla. Tire um print da mensagem.

  - "MODULE_NOT_FOUND" / "Cannot find module 'playwright'"
      As dependencias do robo nao estao instaladas. Rode o instalar.bat.
      Se voltar sozinho depois de um tempo, veja o item do OneDrive abaixo.

  - NAO deixe a pasta do robo dentro do OneDrive
      O OneDrive sincroniza os milhares de arquivos do node_modules e, com
      "Arquivos sob demanda", troca parte deles por atalhos na nuvem. O Node
      nao acha o arquivo e da MODULE_NOT_FOUND, as vezes so as vezes.
      Use C:\Robo-Unimed. Se mover a pasta, confira o ROBO_CAMINHO dentro
      de servidor-local\.env — ele precisa apontar para o novo lugar.

  - "Robo offline" no CRM → verificar se iniciar.bat esta rodando
  - "Playwright not found" → rodar: npx playwright install chromium
  - "Permissao da webcam" → na primeira execucao, clicar "Permitir"
    quando o Chrome perguntar
  - Erros de login → verificar UNIMED_USUARIO e UNIMED_SENHA no .env
